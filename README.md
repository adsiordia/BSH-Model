# BSH Conjugation Model

Predicting bile salt hydrolase (BSH) enzyme activity on bile acid-amine conjugation pairs using machine learning.

## Background

Bile salt hydrolases (BSH) are microbial enzymes that deconjugate bile acid-amine conjugates in the gut. The Lukowski and Dorrestein labs screened a panel of BSH enzymes against combinations of bile acids and amines to identify which enzymes can catalyze novel conjugation reactions. Product formation was measured by LC-MS intensity.

This repository contains the data preprocessing pipeline and model training code for predicting BSH conjugation activity from:

- **Enzyme embeddings** (ProtT5 protein language model)
- **Bile acid molecular fingerprints** (Morgan fingerprints from SMILES)
- **Amine molecular fingerprints**

## Usage

### 1. Data Preprocessing

Run `notebooks/data_preprocessing_BSH_enzyme_model.ipynb` from top to bottom. This will:

- Standardize reactant SMILES and compute molecular descriptors
- Classify bile acids (Mono/Di/Tri hydroxylation) and amines
- Enumerate all possible conjugation pairs via combinatorial chemistry
- Build the heatmap labels table (Enzyme x ProductName x Intensity)
- Load and match ProtT5 enzyme embeddings

All outputs are saved to `outputs/`.

### 2. Model Training

After preprocessing, run `notebooks/BSH_conjugation_model.ipynb` to train the Multiple Instance Learning (MIL) model. The model uses:

- A **PairScorer** MLP that scores each bile acid candidate given the enzyme and amine
- A **Mixer** attention module that weights bile acid candidates
- Enzyme-holdout cross-validation to ensure generalization to unseen enzymes

Alternatively, use the standalone training scripts in `training/` for batch runs:

```bash
python training/BSH_train_10_22_2025.py --data_dir data --out_dir outputs
```

## Data Files

| File | Description |
|------|-------------|
| `bsh_reactants_SMILES.xlsx` | Reactant compound names, SMILES, and types (bile acid / amine) |
| `NEW_Stage2_BAs_amines_for_heatmap_manual.csv` | LC-MS intensity heatmap for amine-specific products |
| `NEW_Stage2_BAs_subs_for_heatmap_manual.csv` | LC-MS intensity heatmap for substitute products |
| `Seqs_list_total.h5` | ProtT5 per-residue embeddings for each enzyme sequence |
| `swap_enumeration_with_core_smiles.xlsx` | Pre-computed enumeration with core SMILES annotations |
