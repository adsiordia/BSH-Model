# BSH Conjugation Explorer

Interactive results from a model predicting which bile salt hydrolase (BSH) enzymes
conjugate which amines onto which bile acid cores.

115 enzymes x 25 amines x 3 bile acid core classes, all measured. The page covers the
assay, the trends in the data, how the model was built, what it gets wrong, and
predictions for sequences that were never tested.

Everything is inlined into a single HTML file — no server, no network calls, no
tracking.

Source, data and trained model: https://github.com/adsiordia/BSH-Model
